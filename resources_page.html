Resources

Tools

  • VS Code — a free code editor (supports Python, JavaScript, and more).
  • Replit — write and share code right in the browser.
  • Scratch — visual programming for games/animations.
  • GitHub — store code, track versions, and collaborate.
  • Google Colab / Jupyter Notebook — run Python without installing anything.
  • MDN Web Docs — official reference for HTML, CSS, JavaScript.

Courses & Labs

  • Khan Academy — beginner-friendly coding and CS basics.
  • Codecademy (free tier) — interactive beginner lessons.
  • Project Euler — math + coding puzzles.
  • LeetCode (easy track) — practice coding challenges.
  • TryHackMe (intro rooms) — hands-on beginner cybersecurity labs.
  • OverTheWire: Bandit — learn Linux and problem-solving through challenges.
